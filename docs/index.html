nxt-opds est un serveur de bibliothèque numérique personnel avec catalogue OPDS et interface Vue 3. librarian est l'agent IA qui enrichit et maintient ce catalogue automatiquement. Deux projets, un seul écosystème.

nxt-opds

Le serveur de bibliothèque

Serveur eBook léger en Go : catalogue OPDS 1.2/2.0, interface web Vue 3, lecteur EPUB intégré, le tout en un seul binaire statique.

  • ✓ Catalogue OPDS 1.2 & 2.0 pour tout lecteur (KyBook, Moon+ Reader, Calibre…)
  • ✓ Upload EPUB avec extraction instantanée des métadonnées
  • ✓ Multi-utilisateurs, profils enfants & classification d'âge
  • ✓ Lecteur EPUB intégré, PWA installable, mode hors-ligne
  • ✓ Serveur MCP pour l'accès des agents IA
Go 1.24 Vue 3 Tailwind CSS SQLite OPDS MCP PWA

librarian

L'agent IA

Agent Go autonome qui pilote une ou plusieurs bibliothèques nxt-opds via leur serveur MCP : enrichissement des métadonnées, chat sur le catalogue, batches de maintenance.

  • ✓ Enrichissement auto : tags, résumés, classification d'âge, séries
  • ✓ Assistant conversationnel branché sur votre catalogue
  • ✓ Maintenance en lot (batch) résiliente aux quotas LLM
  • ✓ Appairage par code one-time, sans copier-coller de secrets
  • ✓ Multi-backends LLM (Anthropic, Ollama Cloud…), image ~25 MB
Go MCP client Anthropic Ollama Docker Daemon

Démarrage rapide

En route en deux minutes

Lancez le serveur, puis appairez l'agent.

📖 Lancer nxt-opds

# Build (Go 1.24+)
go build -o nxt-opds .

# Démarrer avec backend SQLite
AUTH_PASSWORD=secret \
BACKEND=sqlite ./nxt-opds

# Ouvrir http://localhost:8080
# OPDS : http://localhost:8080/opds

🤖 Appairer librarian

# Installer
go install github.com/banux/\
  librarian-agent/cmd/librarian@latest

# Appairer (code généré dans l'admin UI)
librarian pair \
  --nxt-opds https://books.example.com \
  --code     K4Q9-PN2X \
  --name     example

# Enrichir toute la bibliothèque
librarian batch --instance example
nxt-opds librarian Spec OPDS MCP
